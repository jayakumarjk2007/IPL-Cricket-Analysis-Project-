# IPL Cricket Analysis Project

## Libraries used
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter

## Project modules
- Data loading and cleaning
- Match and team statistics
- Toss analysis
- Season-wise winners
- Super-over analysis
- 200+ high-scoring matches
- Batting and bowling analysis
- Orange Cap and Purple Cap
- Player comparison
- Team head-to-head analysis
- Historical winner prediction using Pandas and NumPy
- Interactive Plotly visualization
